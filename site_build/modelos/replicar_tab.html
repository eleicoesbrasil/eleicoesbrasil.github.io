Como replicar tudo na sua máquina

Se você desconfia de algum número, não precisa acreditar neste painel: todos os dados vêm de arquivos públicos do TSE e todo o código está no repositório. O caminho abaixo refaz tudo do zero e permite conferir cada passo.

1. De onde vêm os dados

  • Boletim de urna em CSV (bweb), por UF, de cada turno: uma linha por seção e candidato, com horário de abertura e de encerramento da urna. Portal de dados abertos do TSE, conjuntos “Resultados 2022/2026 - Boletim de Urna”.
  • Locais de votação com coordenadas (eleitorado_local_votacao_AAAA.zip) e votação por seção (votacao_secao_AAAA_UF.zip).
  • Totais por município do 2º turno de 2026, publicados na apuração em resultados.tse.jus.br (um JSON por município), usados enquanto o TSE não publica os CSVs do 2º turno.
  • Arquivos de urna (boletim, log, RDV) por UF, só se você quiser refazer a leitura dos boletins originais.

2. Passo a passo

git clone <endereço do repositório>
cd eleicoes-brasil-secoes

# baixa os dados do TSE (modo mínimo, cerca de 7 GB; confere o sha512 de cada arquivo)
./scripts/01_baixar_tse.sh --minimo dados/tse

# gera os Parquet de presidente por seção
./scripts/02_gerar_parquet.sh dados/tse

# gera os dados do painel e o site (site/index.html)
./scripts/03_gerar_site.sh

# abre o painel
xdg-open site/index.html   # ou abra o arquivo no navegador

Requisitos: Linux ou macOS (ou WSL), curl, sha512sum, Python 3.10 ou mais novo e uv (ou pip). O download é sequencial e com pausa para não sobrecarregar o servidor do TSE. O modo --completo baixa também os pacotes de arquivos de urna (centenas de GB).

3. Como conferir os números

  • Integridade dos arquivos: cada ZIP é comparado com o .sha512 que o próprio TSE publica ao lado. O script apaga o arquivo se o hash divergir.
  • Totais nacionais: com os Parquet em mãos, SELECT sum(votos_13), sum(votos_22) FROM 'data/parquet/presidente_secoes_2026_1t.parquet' deve bater com o resultado oficial do TSE para o 1º turno (Lula 53.879.538 e Flávio 56.104.503 votos).
  • 2º turno de 2026: some os JSON por município em resultados.tse.jus.br/oficial/ele2026/6258/dados/UF/UFMUNICIPIO-c0001-e006258-u.json. O painel usou esses totais: Lula 64.256.232 e Flávio 59.826.041 votos.
  • Horários de fechamento: a coluna encerramento é o relógio local da urna, copiado do boletim. A coluna encerramento_brasilia soma o fuso (Acre +2h; Amazonas, Rondônia, Roraima, Mato Grosso e Mato Grosso do Sul +1h). Você pode refazer a leitura direto dos boletins originais com pipeline/eleicoes_pipeline/urnas_parse.py e comparar.
  • Conferência cruzada independente: o projeto DataUrnas-BR (GitHub, licença MIT) decodifica os mesmos boletins por outro código. Compare as contagens por seção.
  • Todos os gráficos saem dos arquivos de data/derivados/, que são gerados a partir dos Parquet. Nenhum número do painel é digitado à mão.

4. Limites e cuidados

  • O 2º turno de 2026 só tem CSV por seção quando o TSE publicar o conjunto “Boletim de Urna” desse turno. Até lá, o painel usa os totais por município e uma amostra aleatória de boletins para os horários, e informa isso na própria aba.
  • Nos horários, “fora do horário previsto” é medido em relação às 17h de Brasília. Em 2026, a prorrogação decidida pelo ministro Zanin muda a referência para as urnas que estavam abertas na hora da decisão; o painel mostra as duas marcas.
